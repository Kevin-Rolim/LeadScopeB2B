# Validação da versão acadêmica

O executável `Tests/LeadScopeB2B.SmokeTests.csproj` conserva o contrato de nomes, tipos, tamanhos e nulabilidade dos modelos das 14 tabelas. A execução completa cria uma base temporária no SQL Server e testa cadastros, revisão, autorização HTTP, CNAE combinado, CSV, exportação, exclusão lógica e recuperação de conta por SMTP local.

Consulte o README para comandos e pré-requisitos. Resultados efetivamente executados desta revisão são registrados em `Docs/EntregaAcademica.md`.
